Wizard's Keep

A cozy little woodland wizard game. Tend the garden, brew strange things, meet peculiar customers, and keep the night at bay.

Download Merged Binary
Web Install flashes the device directly from the browser (Chrome / Edge recommended).
Download gives you the full merged .bin so you can flash with esptool, PlatformIO, or any other tool.

Requires a Chromium-based browser with Web Serial support and a USB connection for the install button. Installation erases the selected flash region.
